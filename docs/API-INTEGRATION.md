# JI HIGHWAY API 연동 기록

## 개발 브랜치
`feature/v1.0-api-integration` (현재 기본 배포 `main` 미반영)

## 서버리스 함수
- `/api/status`: 키 설정 여부만 반환. 실제 인증 성공 여부 아님
- `/api/ics`: 한국도로공사 IC/JCT 위치정보 (기본 1,000행 요청)
- `/api/cctv?lat=36.6&lon=127.4`: ITS CCTV, 화면에는 HTTPS 영상만 제공
- `/api/pois?q=부산역`: TMAP 장소명 검색
- `POST /api/route`: WGS84 시작·도착 좌표를 TMAP 경로 API로 전달

## 구현 UI
- IC/JCT 별도 실데이터 선택 → TMAP 경로의 거리·시간
- 목적지 POI 검색(후보 선택) 및 GPS 출발 → TMAP 경로
- 주변 CCTV 조회 및 브라우저 직접 재생(제공처 영상형식에 따라 미지원 가능)
- 기본 홈 API 키 설정 상태 확인
- **기존 샘플 조회와 실제 API 조회는 구분**

## 보안
- 소스에 인증키를 저장하지 않음
- 브라우저에 키, 원본 공급자 응답, 내부 인증 오류를 전달하지 않음
- 좌표의 한국 범위 제한 및 POI 검색어 길이 제한
- 사용자가 운행 판단에 오인하지 않도록 샘플 표시
- 외부 호출은 타임아웃, 공급자 오류는 일반 오류로 처리

## 정체상황 추가
- `/api/congestion`: 한국도로공사 실시간 고속도로 정체상황 (VDS/콘존). 전국 정체목록이며 특정 경로와 정확하게 매칭한 결과는 아님.
- `serviceKey`는 서버리스 함수 내부에서만 사용하며 클라이언트로 전달하지 않음.
- 전국 정체 목록 표출 뒤 IC 구간/경로 매칭은 추후 별도 검증.

## 실경로 시각화
- TMAP 응답의 WGS84 경로 좌표를 SVG로 렌더링합니다.
- 화면은 경로 형상 시각화이며 지도 타일 또는 도로공사 정체구간 색상 지도는 아닙니다.
- 브라우저용 지도 SDK 키와 제공처 도메인 정책 검증 전까지 실제 지도 타일 연동을 보류합니다.
