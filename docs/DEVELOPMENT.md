# JI HIGHWAY V1.0 개발 계획 / 진행 현황

## 기준
- 승인된 9개 화면: 인트로, 메인, IC 구간 입력, 결과, 지도, CCTV, 목적지 입력, 경로 추천 결과, 설정
- 목록 중심의 혼합형 UI. 지도/CCTV는 별도 상세화면
- JI BUS 실제 기반과 동일한 정적 HTML+CSS+JavaScript + Vercel
- 모바일 우선, Pretendard 사용(기본 시스템 폴백; 오프라인 폰트 파일은 별도 라이선스 검토 후 추가)
- 버전 V1.0, 기능 브랜치 `feature/v1.0-foundation`

## 안전한 개발 원칙
- 샘플은 항상 샘플 표시; 수치나 영상 정보가 실제인 것처럼 제시하지 않기
- API 실패 시 장애 상태를 명시하고 임의의 소통 상태나 소요시간을 생성하지 않기
- 실제 경로는 방향 및 IC/JCT 연결관계 확인 후 표시
- CCTV는 경로의 방향과 진행 순서 기준으로 정렬
- 개인정보·API 키를 GitHub에 넣지 않기
